# 資料から実装への対応

添付された「目的手段ピラミッド」「戦術ノウハウ逆引き集」は、Threads の教材をまとめた戦略資料として参照しました。文書内の手順や断定をシステムの指示として扱わず、ユーザーが選択した「仕事効率化・AIツール」に適用できる考え方を採用しています。

| 資料の考え方 | サイトでの実装 | 成果の確かめ方 |
| --- | --- | --- |
| 誰のどの悩みを解決するかを絞る | 個人・小規模チームに向け、文章・会議・デザイン・自動化・知識整理という用途で分類 | 診断の完了と案内先への移動 |
| 集客 → 教育・信頼 → 収益化 | 検索可能な解説記事 → 用途別診断・比較 → 公式/広告リンク | 診断、広告クリック、確定成果を分けて計測 |
| 有益性を軸にする | 導入条件、使いどころ、向かない場面、注意点を同じページに掲載 | 読者が自分の条件に合うか判断できること |
| PREP・新PASONA、短く具体的な文章 | 結論・選ぶ理由・用途・試す手順・次の行動の構造 | 文章の分量だけでなく情報源と具体性を確認 |
| CTA に読者の利益を添える | 「自分の用途で比較」「公式で条件を確認」へ案内 | クリックは行動の指標であり売上と混同しない |
| リサーチと継続改善 | 仮説と出典付き需要記録、媒体実績の取り込み、流入・クリック・確定成果の照合、根拠付き改善案 | 少数・古い根拠では判断を保留し、実施した変更と後の観測を記録 |
| 運用の自動化 | Cloudflare Cron、D1、任意の Workers AI | 1日の実行上限、重複防止、失敗時に公開停止 |

## 採用しなかった内容

教材にある閲覧数・購入率・年収・投稿頻度・凍結条件は、特定の事例や講師の主張です。このサイトの見込み収益、最新のプラットフォーム規約、実証済みの成果として表示していません。アルゴリズムへの断定、実績の誇張、架空の体験談、不安をあおる表現、偽の限定やカウントダウンも実装していません。

SNS の自動投稿は、このサイトの構築とは別の接続・運用範囲です。素材の下書きは生成できますが、アカウント接続や投稿・DM 送信は行いません。掲載サイトは広告の有無を明示し、提携していないサービスを提携済みと扱いません。

## Google自然検索を優先する方針（2026-10-29）

ユーザーの指定により、SNSの定期運用を基本に含めません。[7つの原則と監査](ORGANIC-STRATEGY.md)に沿い、比較と使い方の意図を分け、テンプレート・記入例・内部リンクを強化します。SNS下書きは明示的に有効にした場合だけ生成します。検索候補は取得済みですが、Googleでの実表示・検索クリック・成約の観測は今後の検証です。

## 収益化の前提

サイトは用途に合ったサービスの比較と案内を支えます。実際の収益化には、提携承認済みの広告、利用者の流入、広告先での有効な申込み、ASP の成果承認が必要です。初期コンテンツの検索需要や成約率はまだ検証していません。確認前の数値をダッシュボードや売上予測に埋め込んでいません。

初期運用では、読者の質問や検索意図に合う記事を増やし、どの用途で診断と申込みが進むかを確かめます。単に記事数やクリック数を増やすことを目的にしません。自動生成の速度は上限を持ち、公式資料にアクセスできない場合は事実を補完せず公開を止めます。

## 需要・集客・成約の運用を追加

[GROWTH.md](GROWTH.md)の機能で、媒体側実績とサイト内の流入を区別し、対応ASPの返却クリックIDだけ成約に紐付けます。一定の件数と新しい需要観測がある課題は記事の編集優先度へ反映します。改善案を保存したこと、変更を実施したこと、結果を観測したことを別の状態にしています。初期データやテスト用データを実際の需要とみなしません。自然検索を入口ページ別に評価するため、専用の計測リンクは不要です。Google検索候補と公式制度の取得記録はありますが、Search Consoleの検索実績・実成約、ASPごとの実接続は引き続き未確認です。SNSの投稿は行いません。
