## 再調査の実行方法

```sh
# 外部通信をせず、対象URL・ドメインを確認
node scripts/research.mjs --dry-run

# 公式候補ページの取得証跡
node scripts/research.mjs --official

# 日本語の検索候補を取得
node scripts/research.mjs --suggest
```

必要なドメインはドライラン出力に列挙されます。`curl` は既存の `HTTPS_PROXY` とCA信頼設定を継承します。TLS検証は維持し、プロキシ設定の解除・切り替えは行いません。並列数は2、リクエスト時間は最大20秒、本文は最大512KB。同一の許可済みホスト内だけで最大2回リダイレクトを追います。取得したレスポンスのヘッダーやCookieは保存せず、一時ファイルを削除します。

結果は `.research/research-日時.json` に保存します。取得失敗があれば終了コード2、実行エラーは1、すべて取得成功なら0です。公開ページの取得成功でも `programStatus` と `eligibility` は `unverified` のままです。報酬額を自動抽出して確定扱いにはしません。本文の短い抜粋と元URLを人が読み、条件を確認してから、確認日・原文・対象範囲を追記します。

応募・アカウント作成・フォーム送信は実行しません。Google検索候補は、入力語に関連して表示された語の証跡であり、月間検索数や購買意欲の測定値ではありません。候補が空でも「需要なし」と判断せず、取得失敗と空の正常応答を区別します。
